# CodeDuel companion
Install the VSIX in desktop VS Code using Extensions → … → Install from VSIX.
Use Open in VS Code inside your room after the coding phase begins.
Commands: CodeDuel: Run tests; CodeDuel: Return result to room; CodeDuel: Set up Python environment.
Requires Node.js for JavaScript, Python for the FastAPI settings track. No compiler is bundled.
Only user-triggered challenge commands are executed. Code runs locally with your user's permissions.
Results and complexity claims are trust-based, appropriate for friend duels.
